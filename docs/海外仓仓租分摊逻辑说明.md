# 海外仓仓租分摊逻辑说明（技术）

面向报表执行与开发对账。业务口径（通俗说明）见同目录《仓租的分摊逻辑.doc》。

脚本目录：`modules/K_storage_fee_product_info`（**只用新链路**；旧 `K1_HY` / `K2_4PX` / `K3` / `K4` / `runAll_K` 勿作日常入口）。

---

## 1. 业务目标（一句话）

把鸿羽、4PX 海外仓账单上的仓租，先按**存货归属到销售平台与运营负责人**，再在该负责人店铺站点范围内按**订单销量**落到站点，挂到订单利润行；挂不上的进「无平台」，最后由非分销行均摊。

---

## 2. 结果字段（订单已完成-18）

| 字段 | 含义 |
|---|---|
| 海外仓仓租费 | 行级海外仓仓租（含无平台均摊） |
| 原-海外仓仓租费 | 均摊前的行级仓租 |
| 所有仓库-无平台-需要分摊的费用 | 无平台总额（通常仅第 1 行） |
| 仓租分摊 | 无平台均摊到本行的金额 |
| 仓租合计 | FBA仓租费 + 海外仓仓租费 |

挂接键：`站点商品ID识别码 = 站点 + 商品ID`（**不含**运营负责人）。  
金额：仓租相关统一 **4 位小数**（`common/cang_zu_decimal.py`）。

---

## 3. 三段归因（核心口径）

| 阶段 | 跟什么走 | 边界 |
|---|---|---|
| ① 平台 | 该商品在各销售平台的**可售库存-可调**占比 | 排除库存标签「无 / 其他 / ALL」；透传运营负责人 |
| ② 站点 | 订单**销量**阶梯 | 费用只能落在「订单平台 ∩ 该运营负责人」在店铺主数据中的**允许站点**内，**禁止跨负责人** |
| ③ 兜底 | 无平台总额 | 对「产品状态 ≠ 分销」的订单行**平均**分摊 |

守恒：已分摊海外仓仓租费 + 无平台 ≈ 账单总仓租。

---

## 4. 流程与产物

```text
K0 库存周转 Excel（各平台商品ID周转明细）
    → K1_0_HY / K1_0_4PX  → (平台分摊)HY、4PX 仓租明细
    → K1_3（+ 订单15 + 店铺主数据）→ (平台分摊)所有-海外仓-仓租明细
    → K1_4 → 订单16（月报另写 FBA仓租费）
    → K5 → 订单17 → K6 → 订单18
```

日期：`config/A0_set_date.py`（`folder_name` / `shared_date` / `ku_cun_date`）。

### 4.1 K0

- 源：`snapshot_market_turnover`
- 产出：`…\仓租\{ku_cun_date}库存动销明细.xlsx`
- 下游用 sheet：**各平台商品ID周转明细**（商品ID、销售平台、可售库存-可调、运营负责人）

### 4.2 K1_0（HY / 4PX）— 账单 → 销售平台

| | HY | 4PX |
|---|---|---|
| 账单 | `仓租\鸿羽\*{日期}.xlsx` | `仓租\4PX\4PX法国仓-仓租明细-{日期}.xlsx` |
| 汇总 | 产品金额 → 产品代码 | 应收金额 → SKU |
| 映射 | warehouse → product_sku → 商品ID（DB） | 同左 |
| 产出 | `(平台分摊)HY-仓租明细.xlsx` | `(平台分摊)4PX-仓租明细.xlsx` |

\[
\text{海外仓仓租费}=\text{总仓租}\times\frac{\text{该销售平台有效库存}}{\text{该商品ID有效库存合计}}
\]

- Sheet「平台分摊」含运营负责人；Sheet「无平台-仓租费用」含原因。  
- 映射缺失：写待补全 mapping 并中止（可先 `upProductMapping.py`）。  
- HY 仅去前缀 `900008-`。

### 4.3 K1_3 — 合并两仓 → 站点

1. 合并键：`商品ID + 销售平台 + 运营负责人`  
2. 销售平台 → 订单「平台」  
3. **允许站点** = 启用店铺中 `平台=market_code` 且 `运营负责人=ops_owner` 的站点（`platform_shop`）  
4. 阶梯（均在允许站点内）：

| 级 | 规则 |
|---|---|
| L1 | 该商品在允许站点有销量 → 按该商品站点销量占比 |
| L2 | 否则按允许站点内平台总销量加权（同负责人） |
| L4 | 否则默认主站且该站在允许集合内 |
| L5 | 否则 → 无平台 |

不做：全平台摊、跨负责人均摊。  
产出：`(平台分摊)所有-海外仓-仓租明细.xlsx`（无平台 = 两仓原无平台 + L5）。

### 4.4 K1_4 — 挂订单（15→16）

1. 读 Sheet「平台分摊」  
2. 按 `站点商品ID识别码` **先 sum 费用**（同键可能多负责人）再 merge  
3. 订单无而仓租有的识别码行追加  
4. 透传无平台 → `所有仓库-无平台-需要分摊的费用`（第 1 行）  

月报：之后 `C2_ManoRent合并` 写 `FBA仓租费`。

### 4.5 K5 / K6（16→17→18）

- K5：补运营模式、供应商、分类、产品状态等（写出前人工检查）  
- K6：分销口径收尾；无平台总额 ÷ 非分销行数 → 仓租分摊；重算海外仓仓租费与仓租合计（4 位小数）

## 6. 对账清单

| 现象 | 检查 |
|---|---|
| 平台分摊无平台偏多 | 仓库 SKU→商品ID 映射；K0 有效库存；`-NW` 商品ID 是否与 K0 一致 |
| 站点分摊无平台偏多 | 负责人是否与店铺主数据 `ops_owner` 一致；该平台是否有启用站点；订单站点是否在允许集合 |
| 挂不上订单 | 站点原文是否与订单15一致（含 LM 后缀） |
| 金额不平 | 控制台核对合计；是否全程 4 位小数 |

## 7. 新旧差异（摘要）

| | 旧 | 新 |
|---|---|---|
| 映射 / 库存 | Excel 手工 | DB mapping + K0 快照 |
| 站点 | 壳站点 + 二次挪费 / LM-BC 对半 | 负责人允许站点 + 订单真实站点销量 |
| 挂订单 | K4 改站点挪费 | 仅识别码合并（先按识别码汇总） |
| 精度 | 不统一 | 统一 4 位小数 |
